MAERS QLS // USER GUIDE

项目使用说明

重要：请仅在一个标签页中编辑数据。修改并保存后，请刷新其他已打开的标签页，再继续操作,避免数据出现问题。

项目简介

MAERS QLS 是个人时间规划与生活记录工具，由 Schedule 和 QuantiLife 两部分组成。可以分别使用，也可以通过活动类别和计时记录让计划与实际回顾相互衔接。

Schedule｜时间规划

  • 规划表：按日期和时间安排活动，可用分类颜色区分活动类型，长按显示详情；点今跳回今天，点图层按钮显示被更长时间块覆盖的块。可自选时段查看。
  • 时间轴：按时间顺序浏览和整理安排。长按显示备注。
  • 进行中：开始专注计时，完成后保留实际投入的时间记录，可调整时间或标记心情。
  • 期望：记录各类别的目标时长，用于安排与回顾。

QuantiLife｜生活量化

  • 记录每日步数、睡眠、饮食与热量、活动和心情等生活数据。
  • 在统计/报告页面查看记录汇总，帮助回顾生活节奏。

数据与设置

  • 联动：Schedule 完成的计时活动可同步到 QuantiLife；规划表中的期望时长也可同步到 QuantiLife 的期望设定。
  • 备份：主页的下箭头导出全项目备份；上箭头导入。建议定期导出并妥善保存文件。
  • 主题：顶部按钮支持三种模式循环切换：
    • 跟随系统（屏幕图标）
    • 深色模式（月亮图标）
    • 浅色模式（太阳图标）
  • 本地数据：记录保存在当前浏览器中；清理浏览器数据或更换设备前，请先导出备份。
