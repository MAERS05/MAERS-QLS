# 文件功能说明

本文件提供职责、入口和依赖导航。开发约束见[开发规范](开发规范.md)，模块协作方式见[前端开发指南](前端开发指南.md)，数据结构集中见[数据保障与存储迁移](数据保障与存储迁移.md)。

## 页面入口

| 页面 | 模块入口 | 功能 |
| --- | --- | --- |
| [门户](../index.html) | [portal-entry.js](../common/js/portal-entry.js) | 子系统导航、默认入口设置、全项目备份、使用说明 |
| [Schedule](../MAERS-Schedule/index.html) | [entry.js](../MAERS-Schedule/js/entry.js) | 规划表、时间轴、进行中计时 |
| [QuantiLife 记录](../MAERS-QuantiLife/index.html) | [entry.js](../MAERS-QuantiLife/js/entry.js) | 每日基础指标、饮食、时间事件、心情与期望 |
| [QuantiLife 报告](../MAERS-QuantiLife/report.html) | [report-entry.js](../MAERS-QuantiLife/js/report-entry.js) | 趋势、排行和下钻 |

每个页面由单个 ES 模块入口装载依赖图；[theme-boot.js](../common/js/theme-boot.js) 是提前运行的主题引导。入口最终发布兼容接口，业务逻辑位于它们导入的职责模块。
